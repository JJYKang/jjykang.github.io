Padding and Boundary Handling

Both implementations use zero padding and return the same image size by default. The 9×9 box filter uses four zeros on each side; the finite difference filters use one zero on each side along their filtering axis. Zero padding darkens the blurred image at the border and creates derivative responses along the frame.

Bells & Whistles: Gradient Orientations

I computed orientations from the smoothed DoG gradients without built-in angle functions. I reduced the derivative ratio to the first octant, approximated arctangent with a 12-term series, then restored the octant and quadrant from the derivative signs and magnitudes. Angles increase clockwise from the right because image y increases downward.

Hue shows gradient direction, saturation is one, and brightness shows magnitude scaled by its 99th percentile and clipped to [0, 1]. Flat regions are black. The gradient points toward increasing intensity, perpendicular to the edge.

Part 2: Fun with Frequencies

Part 2.1: Image Sharpening

A Gaussian retains low frequencies. Subtracting this blur from the image gives the high-frequency detail: H = I − I ∗ G. Unsharp masking adds a scaled version back: Isharp = I + αH. This increases local contrast around edges.

I combined the operation into one filter: K = (1 + α)δ − αG, where δ is an impulse at the kernel center. Each RGB channel is convolved with K using symmetric padding. All results use a 9×9 Gaussian with σ = 2; values are clipped to [0, 1] only when saving.

Taj Mahal and Sharpening Strength

The high-frequency displays below show 0.5 + 4H: gray is zero, with signed details amplified for visibility. This display scaling is not used for sharpening.
