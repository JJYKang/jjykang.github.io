Padding and Boundary Handling

Padding allows the filters to reach the image boundaries without shrinking the output. The box filter needs four rows or columns of zeros on each side; the difference filters need one along their filtering direction. This introduces some border effects: the box-filtered selfie darkens at the frame, and the difference filters respond to the jump between the photograph and the zeros.

Bells & Whistles: Gradient Orientations

  1. Calculate direction: Use the smoothed x/y derivatives from 1.3. Divide the smaller derivative magnitude by the larger so only an angle between 0° and 45° needs to be approximated. Skip the division where both derivatives are zero.
  2. Approximate the angle: Use a 12-term alternating arctangent series. For ratios above tan(22.5°), replace the ratio r with (r − 1)/(r + 1), then add 45° back after the approximation. This keeps the series input small enough to converge quickly.
  3. Recover the direction: If the y derivative has the larger magnitude, subtract the angle from 90°. Use the signs of the x and y derivatives to place it in the correct quadrant, then wrap it to a full turn. No built-in angle function is needed.
  4. Assign colors: Map the resulting direction to hue, keep saturation at one, and use gradient magnitude for brightness. Weak responses stay dark so flat areas do not compete with the visible edges.

Part 2: Fun with Frequencies

Part 2.1: Image Sharpening

  1. Blur: Apply a 9×9 Gaussian with σ = 2 to each color channel. This retains the broad shading and suppresses fine detail.
  2. Extract detail: Subtract the blur from the original. The remainder contains the edges and texture weakened by the Gaussian.
  3. Sharpen: Add a multiple of that remainder back to the original. The amount α controls how strongly the existing detail is emphasized.

To perform this in one convolution, the implemented kernel is K = (1 + alpha) * delta - alpha * G, where delta is one at the center and zero elsewhere. This combines the original-image contribution and the subtracted Gaussian blur in a single filter.

Part 2.2: Hybrid Images

  1. Align: Select two matching landmarks in each image. Scale the second image to match the landmark spacing, rotate to match the line between them, and translate to bring the landmarks together. Resample with bilinear interpolation, without a separate anti-alias filter, then crop both images to an area with valid content from each.
  2. Keep the broad structure: Gaussian-blur the first image to retain its low frequencies.
  3. Keep the detail: Subtract a Gaussian-blurred copy from the second image to retain its high frequencies.
  4. Combine: Add the two filtered images. Check the result close up and at a smaller viewing size, adjusting the blur scales if either source overwhelms the other.

Part 2.3: Gaussian and Laplacian Stacks

  1. Gaussian stack: Start with the original image, then blur the previous level using σ = 2, 4, 8, 16, and 32. All six levels keep the same dimensions; the increasing blur separates fine texture from broader shading without downsampling.
  2. Convolution: Build each Gaussian from a 1D kernel extending three standard deviations on either side, then filter along rows and columns separately, reflecting the image at the borders. This gives the same filtering as the corresponding 2D kernel at a lower cost.
  3. Laplacian stack: Subtract the next, more blurred Gaussian image from each level. Keep the last Gaussian as well, since the differences alone would lose the broad color and shading needed to reconstruct the image.

Part 2.4: Multiresolution Blending

  1. Separate the image scales: Build the Gaussian and Laplacian stacks for both inputs using the six levels from 2.3.
  2. Build the mask stack: Start with the binary mask and blur it at the same scales. White selects the first image and black selects the second.
  3. Blend each level: Multiply the first image's band by the mask and the second image's band by its complement, then add the contributions.
  4. Reconstruct: Sum the blended bands, including the last blurred level. This lets the broad lighting transition spread farther than the fine detail.

The apple/orange result in 2.3 uses a straight split. For each custom pair, the binary mask selects pixels to the left of a boundary that follows one gentle sine wave down the image, centered at half the width. The sideways variation is 4% of the width for the drinks and 5.5% for the landscapes, placing the join through the cups and between the landscape subjects.
